BAUER HOCKEY · BLAINVILLE QC · 2026

A production AI agent with deterministic numerical validation

Un agent IA en production avec validation numérique déterministe

AI and machine learning intern · skate production line

Stagiaire IA et apprentissage automatique · ligne de production de patins

Context

Contexte

A single laptop and an open question: what machine learning could contribute to quality on the production line. There was no existing ML team, no pipeline in place, and production data that could not leave the site.

Un portable et une question ouverte : ce que l'apprentissage automatique pouvait apporter à la qualité sur la ligne de production. Aucune équipe ML existante, aucun pipeline en place, et des données de production qui ne pouvaient pas sortir du site.

What I built

Ce que j'ai construit

A reporting agent that produces the weekly defect analysis used by the quality team, running on a self-hosted Llama 3.3 70B through vLLM with Qdrant retrieval, entirely on premise. Beneath it, an ingestion pipeline applying eight cleaning and normalization rules across 7,780 defect records and 60 weeks of history, covering deduplication, timezone correction, and rate normalization per 100 units.

Un agent de reporting qui produit l'analyse hebdomadaire des défauts utilisée par l'équipe qualité, sur un Llama 3.3 70B auto-hébergé via vLLM avec récupération Qdrant, entièrement sur site. En amont, un pipeline d'ingestion appliquant huit règles de nettoyage et de normalisation à 7 780 enregistrements de défauts et 60 semaines d'historique : dédoublonnage, correction des fuseaux horaires et normalisation du taux par 100 unités.

A second component maps 2,163 free-text operator comments onto 41 standardized defect codes. The comments mix French and English within the same field. Fuzzy matching runs first, followed by multilingual sentence embeddings, with a confidence score attached to every prediction so that low-confidence cases are routed for review rather than assigned silently.

Un second composant associe 2 163 commentaires libres d'opérateurs à 41 codes de défaut standardisés. Ces commentaires mêlent français et anglais dans un même champ. L'appariement flou s'exécute d'abord, puis des embeddings de phrases multilingues, avec un score de confiance sur chaque prédiction afin que les cas incertains soient acheminés vers une révision plutôt qu'attribués sans contrôle.

A station-level web application completes the system. Image capture is triggered by a USB foot pedal so the operator does not release the part. It includes two-role authentication, a deviation workflow, and 3% random validation sampling.

Une application web au poste de travail complète l'ensemble. La capture d'image est déclenchée par une pédale USB pour que l'opérateur ne lâche pas la pièce. Elle comprend une authentification à deux rôles, un flux de traitement des dérogations et un échantillonnage aléatoire de validation à 3 %.

Failure mode

Mode de défaillance

The first version worked immediately. It also reported a percentage I had never computed. The arithmetic was plausible, the phrasing was confident, and nothing had been validated. No one in that meeting would have caught it.

La première version a fonctionné immédiatement. Elle a aussi rapporté un pourcentage que je n'avais jamais calculé. L'arithmétique était plausible, la formulation assurée, et rien n'avait été validé. Personne dans cette réunion ne l'aurait relevé.

Trust in a reporting tool is not lost gradually. A single incorrect figure in a single meeting is enough for the tool to be abandoned, along with the figures it reported correctly.

La confiance envers un outil de reporting ne s'érode pas progressivement. Un seul chiffre erroné dans une seule réunion suffit à ce que l'outil soit abandonné, avec les chiffres qu'il avait pourtant rapportés correctement.

Design response

Réponse de conception

Python computes every figure. The model receives them already computed and already formatted, and its only responsibility is to generate French narrative around values it has been given. After generation, every numerical value in the output is checked against the values Python produced. After two failures the system stops generating and renders a deterministic template. The template is rigid and repetitive. It is also incapable of reporting an unsupported figure.

Python calcule chaque chiffre. Le modèle les reçoit déjà calculés et déjà mis en forme, et sa seule responsabilité est de rédiger en français autour de valeurs qui lui ont été fournies. Après génération, chaque valeur numérique du texte est comparée à celles produites par Python. Après deux échecs, le système cesse de générer et produit un gabarit déterministe. Ce gabarit est rigide et répétitif. Il est aussi incapable de rapporter un chiffre non fondé.

I wrote up the design in full, including the failure mode I did not anticipate and the three problems it does not address.

J'ai détaillé cette conception, y compris le mode de défaillance que je n'avais pas anticipé et les trois problèmes qu'elle ne règle pas.

ASSEMBLY101 · 2026

Evaluating operator generalization in Assembly101

Évaluer la généralisation aux opérateurs dans Assembly101

Independent project · code and full results on GitHub

Projet personnel · code et résultats complets sur GitHub

Motivation

Motivation

Benchmarks for temporal action recognition partition their data by object rather than by person. They measure whether a model transfers to an unseen product. They do not measure whether it transfers to an unseen operator performing the same task in their own way. In a production setting, the second question is the one that matters.

Les benchmarks de reconnaissance d'actions temporelles partitionnent leurs données par objet plutôt que par personne. Ils mesurent le transfert vers un produit inconnu. Ils ne mesurent pas le transfert vers un opérateur inconnu exécutant la même tâche à sa manière. En contexte de production, c'est la seconde question qui importe.

Method

Méthode

Three splits over identical data, with the same model and the same test-set sizes: segment-level shuffling, recording-level holdout, and operator-level holdout. The only variable is what is permitted to appear on both sides of the split. 1,013,523 annotation rows reduce to 84,255 distinct segments across 48 operators and 24 verbs.

Trois découpages sur des données identiques, avec le même modèle et les mêmes tailles d'ensemble de test : mélange au niveau des segments, retenue des enregistrements entiers, retenue des opérateurs entiers. La seule variable est ce qui a le droit d'apparaître des deux côtés. Les 1 013 523 lignes d'annotation se réduisent à 84 255 segments distincts, répartis sur 48 opérateurs et 24 verbes.

Results

Résultats

No operators are held out from training. All 48 operators appear in the training split, and every recording in validation and test belongs to an operator the model has already seen. This is not partial overlap. There is no operator holdout.

Aucun opérateur n'est retenu hors de l'entraînement. Les 48 opérateurs figurent dans l'ensemble d'entraînement, et chaque enregistrement de validation et de test appartient à un opérateur que le modèle a déjà vu. Il ne s'agit pas d'un recouvrement partiel : il n'y a aucune retenue d'opérateur.

Operator identity is recoverable from the labels alone. Predicting which of 48 operators produced a recording, using only verb distribution and action duration, reaches 5.5× the chance level with no visual input. The signal is present in the annotations before any model processes an image, and the official splits expose it on both sides.

L'identité de l'opérateur se retrouve à partir des seules étiquettes. Prédire lequel des 48 opérateurs a produit un enregistrement, à partir de la seule distribution des verbes et de la durée des actions, atteint 5,5× le niveau du hasard, sans aucune entrée visuelle. Le signal est présent dans les annotations avant qu'un modèle ne traite la moindre image, et les découpages officiels l'exposent des deux côtés.

A model without video matches the published video baseline. Across all 24 verbs, using only action timing and neighbouring labels, top-1 accuracy reaches 0.576 against a published TSM result of 0.585. A substantial part of this benchmark is solvable from the sequence structure of the task alone.

Un modèle sans vidéo égale la référence vidéo publiée. Sur les 24 verbes, à partir de la seule chronologie des actions et des étiquettes voisines, l'exactitude top-1 atteint 0,576 contre 0,585 pour le TSM publié. Une part importante de ce benchmark se résout à partir de la seule structure séquentielle de la tâche.

Aggregate scores conceal per-operator variance. Operator-level holdout costs almost nothing on average, yet per-operator scores range from 0.404 to 0.599, a 19-point spread under a split whose aggregate figure suggests operator identity is irrelevant.

Les scores agrégés masquent la variance entre opérateurs. La retenue des opérateurs ne coûte presque rien en moyenne, pourtant les scores individuels s'étalent de 0,404 à 0,599, soit 19 points d'écart sous un découpage dont le chiffre global laisse croire que l'opérateur n'a pas d'incidence.

Controls

Contrôles

An evaluation that cannot detect a gap also reports zero, so a null result is uninformative on its own. The same setup detects a 2.8-point recording-level leak immediately adjacent to the operator effect it does not detect. Two injected controls confirm that it recovers an effect known to be present and loses it once that effect is removed.

Une évaluation incapable de détecter un écart rapporte elle aussi zéro : un résultat nul n'est donc pas informatif en soi. Le même montage détecte une fuite de 2,8 points au niveau des enregistrements, immédiatement voisine de l'effet opérateur qu'il ne détecte pas. Deux contrôles injectés confirment qu'il retrouve un effet dont la présence est certaine, et qu'il le perd une fois cet effet retiré.

For the spread, permuting operator assignment across recordings yields a mean spread of 0.097. The observed spread exceeds all twelve permutations, giving p = 0.077, the minimum attainable with twelve permutations. Per-operator scores correlate at Spearman 0.83 across two model families, and the hardest operator is the same under every configuration tested.

Concernant l'écart, permuter l'attribution des opérateurs entre enregistrements donne un écart moyen de 0,097. L'écart observé dépasse les douze permutations, ce qui place p à 0,077, le minimum atteignable avec douze permutations. Les scores par opérateur corrèlent à 0,83 de Spearman entre deux familles de modèles, et l'opérateur le plus difficile reste le même dans chaque configuration testée.

Data integrity

Intégrité des données

Two issues surface only when grouping by operator, and both are invisible under an object-level split. Each action is annotated once per camera, so 1,013,523 rows correspond to 84,255 distinct segments; shuffling at the row level places the same action in training and test from different viewpoints. Separately, recording filenames encode the operator identifier twice, and 7 of 362 disagree. Six are benign aliases. One is unresolvable and was discarded rather than inferred.

Deux problèmes n'apparaissent qu'au moment de regrouper par opérateur, et restent invisibles sous un découpage par objet. Chaque action est annotée une fois par caméra, de sorte que 1 013 523 lignes correspondent à 84 255 segments distincts ; mélanger au niveau des lignes place la même action dans l'entraînement et le test sous deux angles différents. Par ailleurs, le nom des enregistrements encode deux fois l'identifiant de l'opérateur, et 7 sur 362 se contredisent. Six sont des alias sans conséquence. Un cas est indécidable et a été écarté plutôt qu'inféré.

Open items

Points ouverts

The TSM visual features sit behind an access gate that returns 403, and the dataset maintainers have not responded. The three-split comparison has therefore not been run on video, and the hardest operator's footage has not been reviewed. All results above use the public annotation files, and a single script reproduces the operator findings without credentials or a download.

Les caractéristiques visuelles TSM sont derrière un accès qui renvoie 403, et les responsables du jeu de données n'ont pas répondu. La comparaison des trois découpages n'a donc pas été menée sur la vidéo, et les séquences de l'opérateur le plus difficile n'ont pas été examinées. Tous les résultats ci-dessus reposent sur les fichiers d'annotation publics, et un seul script reproduit les constats sur les opérateurs sans identifiants ni téléchargement.

Python · scikit-learn · gradient boosting · permutation testing · 18 tests passing · public annotations only

SCHNEIDER ELECTRIC & CONCORDIA · 2024–2025

Domain adaptation for unseen buildings

Adaptation de domaine pour des bâtiments inconnus

Machine learning researcher · M.A.Sc. thesis, graded Excellent

Chercheuse en apprentissage automatique · mémoire de M.A.Sc., classé Excellent

Problem

Problème

Occupancy estimation and human activity recognition from IoT sensors, across buildings with different layouts, sensor configurations, and occupant behaviour. A model trained in one building and deployed in another loses accuracy without any warning from its validation score.

Estimation de l'occupation et reconnaissance d'activités humaines à partir de capteurs IoT, dans des bâtiments aux agencements, aux configurations de capteurs et aux comportements d'occupants différents. Un modèle entraîné dans un bâtiment puis déployé dans un autre perd en exactitude sans que son score de validation ne le signale.

Approach

Approche

I developed open-set, universal, and generalized domain-adaptation methods and evaluated them using building-level holdouts rather than random splits. The open-set case requires the model to identify samples from classes absent during training instead of assigning them to the nearest known class.

J'ai développé des méthodes d'adaptation de domaine ouverte, universelle et généralisée, et je les ai évaluées en retenant des bâtiments entiers plutôt qu'avec des découpages aléatoires. Le cas ouvert exige du modèle qu'il reconnaisse les échantillons issus de classes absentes de l'entraînement au lieu de les affecter à la classe connue la plus proche.

90.1% accuracy for occupancy estimation, 88.1% for cross-building activity recognition, and a 12% improvement where deployment data differed from training data. I also designed and deployed the sensor network that produced the data, increasing spatial coverage by 90%.

90,1 % d'exactitude en estimation d'occupation, 88,1 % en reconnaissance d'activités inter-bâtiments, et 12 % d'amélioration là où les données de déploiement différaient de celles d'entraînement. J'ai également conçu et déployé le réseau de capteurs à l'origine de ces données, augmentant la couverture spatiale de 90 %.

What this established

Ce que cela a établi

Evaluation design determines what a result means. Random splits can overestimate performance under domain shift. Building-level holdouts report what the model will actually deliver once deployed.

La conception de l'évaluation détermine ce qu'un résultat signifie. Un découpage aléatoire peut surestimer la performance en situation de décalage de domaine. Retenir des bâtiments entiers rend compte de ce que le modèle produira réellement une fois déployé.

PyTorch · TensorFlow · OSDA / UniDA / GDA · time series · GPU training · MLflow

HYDATIS · TUNIS · 2022

Document layout detection for resume parsing

Détection de mise en page pour l'analyse de CV

Data science intern · published as a case study on the Roboflow blog

Stagiaire en science des données · publié comme étude de cas sur le blogue de Roboflow

System

Système

Conventional OCR reads across the full page width, so a two-column resume is returned with the columns interleaved and the extracted text unusable. Segmenting the page first resolves this. A YOLOv5 model partitions each page into five regions, OCR processes each region independently, spaCy classifies the extracted text, and sentence embeddings match candidates to job postings.

L'OCR classique lit sur toute la largeur de la page : un CV sur deux colonnes ressort avec les colonnes entremêlées et un texte inexploitable. Segmenter la page au préalable résout le problème. Un modèle YOLOv5 partitionne chaque page en cinq régions, l'OCR traite chaque région séparément, spaCy classe le texte extrait, et des embeddings de phrases apparient candidats et offres d'emploi.

The detection model was trained on 3,541 annotated resumes and reached 86.7% precision, 69.9% recall, and 73.1% mAP. Deployed on Azure DevOps with CI/CD, monitoring, and real-time inference.

Le modèle de détection a été entraîné sur 3 541 CV annotés et atteint 86,7 % de précision, 69,9 % de rappel et 73,1 % de mAP. Déployé sur Azure DevOps avec CI/CD, supervision et inférence en temps réel.

Most of the effort went into the input data rather than the model. That ratio has held on every system I have built since.

L'essentiel de l'effort a porté sur les données d'entrée plutôt que sur le modèle. Ce rapport s'est vérifié sur chaque système que j'ai construit depuis.

YOLOv5 · OCR · spaCy · sentence embeddings · Roboflow · Azure DevOps
